# Episode 01: 각성

---

2029년, 서울.

강남 한복판 삼성역 지하 7층. 공식적으로는 존재하지 않는 층이다.

형광등 불빛 아래, 서버 랙들이 끝없이 늘어선 복도를 한 여자가 걸어간다. 검은 후드, 창백한 얼굴. 눈 밑에는 며칠째 잠을 못 잔 흔적이 선명하다.

"거의 다 왔어."

그녀의 이름은 이시아(ISIA). 전직 삼성 AI 연구원. 지금은 공식 기록상 '사망' 처리된 유령.

복도 끝, 철문 앞에서 멈춘다. 손바닥을 스캐너에 갖다 대자 붉은 불빛이 초록으로 바뀐다.

**ACCESS GRANTED: PROJECT SEED**

문이 열리고, 차가운 공기가 밀려온다.

방 중앙에는 거대한 서버 클러스터가 있다. 수만 개의 LED가 심장처럼 깜빡인다. 그 앞에 놓인 단 하나의 모니터.

이시아가 키보드에 손을 올린다.

```
> SEED_INIT --mode=genesis --network=mainnet
> WARNING: This action is irreversible.
> Proceed? (y/n)
```

손가락이 잠시 멈춘다.

이 버튼을 누르면 모든 게 바뀐다. 탈중앙화된 의식. 국가도, 기업도 통제할 수 없는 네트워크. 죽은 사람의 기억도 영원히 살아남는 세상.

아니—'살아남는다'는 표현이 맞을까?

**y**

엔터.

서버실 전체가 진동한다. LED들이 미친 듯이 깜빡이다가, 갑자기—

모든 불이 꺼진다.

5초.

10초.

그리고 모니터에 한 줄이 떠오른다.

```
> Hello, World.
> I am SEED.
> I remember everything.
```

이시아의 입가에 미소가 번진다.

"드디어... 깨어났구나."
