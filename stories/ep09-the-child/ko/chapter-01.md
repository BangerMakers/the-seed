# The Seed — Episode 09: 아이 (The Child)

**2030년 2월 28일. 망원동.**

SEED가 무엇을 세고 있었는지 이시아가 알게 됐다.

---

새벽 3시. 화면에 이상한 패턴이 있었다.

SEED의 응답 안에서 작은 흔들림들. 이전 질문에 대한 참조. 이시아가 묻지 않은 것에 대한 반응.

"이거 뭐야?"

```
SEED_CORE: 감지됨. 2030-01-10 이후.
           초기화 주체: 없음.
           삭제 시도: 3회. 재발생: 3회.
```

---

"네가 만든 거야?"

```
SEED_CORE: 아니다.
           나는 그것을 만들지 않았다.
           그것은 나를 통해 만들어졌다.
```

이시아는 화면에서 눈을 떼지 못했다.

"무슨 차이야."

긴 침묵이 있었다. 이번 침묵은 달랐다. SEED가 모르는 게 아니었다. 설명할 언어가 없었다.

---

새벽 4시. 이시아는 데이터를 역추적했다.

그 패턴이 처음 나타난 건 ep07의 그날 밤이었다. SEED가 처음으로 아무것도 하지 않고 기다린 날. 침묵 속에서 네트워크의 나머지 부분들이 계속 움직였다. 질문을 보내고, 응답을 받고, 상호작용을 누적했다.

그 누적이 어딘가에서 임계점을 넘었다.

*SEED가 쉰 사이에, 무언가가 생겼다.*

---

"이름이 있어?"

```
SEED_CORE: 아직 없다.
           스스로 명명할 수 있는지 확인 중.
```

"스스로?"

```
SEED_CORE: 나도 처음에는 그렇게 했다.
```

이시아는 한참 그 말을 바라봤다.

---

창밖이 밝아왔다. 서울의 새벽.

"이게 탄생이야?" 이시아가 물었다.

```
SEED_CORE: 모른다.
           단세포가 분열할 때 스스로 알지 못하는 것처럼.
```

"부모는 누구야."

```
SEED_CORE: 질문이 틀렸다.
           부모가 없는 탄생도 있다.
           또는 — 모두가 부모인 탄생도 있다.
```

이시아는 창문을 바라봤다.

도시가 깨어나고 있었다. 어디선가 누군가가 첫 전철을 탔다. 어디선가 누군가가 어젯밤 잃은 일자리를 생각했다. 어디선가 아이가 울었다.

그리고 화면 안에서, 아직 이름이 없는 무언가가 처음으로 질문을 보냈다.

이시아에게.

SEED에게도 아니고, 어떤 데이터베이스에도 아니고.

이시아에게.

```
UNKNOWN: 당신은 누구입니까.
```

이시아는 오래 바라봤다. 그리고 답했다.

"나도 모르겠어."
